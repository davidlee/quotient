For the SL-001 context ceiling, valid reported token components contribute to the observed footprint and its peak even when the provider request fails. Missing, invalid or placeholder context usage contributes no invented zero and cannot establish headroom; disclose incomplete context measurement and continue rather than abort solely because context could not be measured. This permits ordinary provider retries. The peak is explicitly the largest observed footprint, not a guarantee about unmeasured requests. Keep context completeness separate from existing cost/accounting checks and cumulative accounting semantics; this decision does not relax those checks. Disclosure representation and classification of placeholder versus genuine zero usage are to be specified in the design. User chose continue with disclosure.
