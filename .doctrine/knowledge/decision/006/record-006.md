For SL-001, validate cost and token/context measurements independently. Valid reported cost with absent or invalid token fields permits continuation with the context gap disclosed. Missing or invalid cost retains the accounting stop for ordinary usage-bearing responses, including the existing exceptions for failed sends with placeholder usage and summarization retries. This deliberately replaces the existing coupled readUsage requirement that invalid tokens alone make accounting unknown even when cost is known. Under the new status contract, accounting validity governs cost measurement; cumulative token fields remain reporting totals and their context measurement gaps are disclosed separately. Context measurement does not require cost validity; a measured crossing still takes the existing ceiling precedence over accounting failure. Update the design, new status/result contracts and focused tests to state the distinction explicitly.
