Run one pi agent under the operator's policy and answer with its reduced transcript, status and verdict. Trust `result` only when `final` is true; a `refused` state means nothing ran. Pass `session` back to continue a conversation. A client that declares MCP tasks gets a task to poll instead. A cancelled task carries no result, but `pi_agent_wait` naming its task id still reads the run's document. To run several at once without tasks, use `pi_agent_start` and `pi_agent_wait`.
