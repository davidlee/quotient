Acknowledge settled or lost runs and answer `pi-agent-ack/1`. An acknowledged run drops out of a `pi_agent_wait` that names no runs, which is how a caller that lost its ids finds the results it has not used; it can still be waited on by id. A run not yet settled answers `acknowledged: false` with reason `not-settled`; a run this server does not hold answers `unknown`. Acknowledging twice is harmless. Every id is checked before any is acknowledged.
